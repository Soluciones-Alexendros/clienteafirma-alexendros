# Alertas heredadas del Cliente @firma oficial

Este fork mantiene el código de [ctt-gob-es/clienteafirma](https://github.com/ctt-gob-es/clienteafirma). Muchas alertas de code scanning están en código que es igual en el oficial. Aquí se anota, regla a regla, qué decidimos y por qué.

## Cómo se decide el origen
Una alerta es «oficial» si la línea señalada existe igual en `upstream/master`. Si no, es «nuestra» y se arregla.
